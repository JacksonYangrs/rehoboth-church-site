# 利河伯教会网站 v2 — 设计文档（公开网站 + 管理后台）

> 目标：把「利河伯教会网站」从静态展示升级为「可记录、可纪念、可沟通」的教会线上家园。
> 架构：公开网站保持静态（GitHub Pages）＋ Cloudflare Workers 后台（D1 数据库 + R2 照片 + Stream 视频）。
> 状态：**设计待确认**（确认后进入开发）。

---

## 1. 网站定位（已确认）

- **线上敬拜神的所在** + **会众为神作见证的记录之地**
- 日常敬拜活动（照片/视频/文字）值得被纪念 → 记录下来，供大家回顾、观看、学习
- 教会通过线上做**会员发展与接纳**（面向非基督徒）
- 提供**爱心窗口**（匿名诉说 + 远程辅导）
- **每周查经公告**自动发布

## 2. 总体架构（方案 A，已确认）

```
┌─────────────────────────────────────────────────────┐
│  公开网站（静态，GitHub Pages，现有技术栈不变）          │
│  首页 / 认识教会 / 灵修 / 敬拜 / 成长×6专栏 /           │
│  查经公告 / 建堂 / 奉献 / 爱心窗口                       │
│       │  fetch 公开只读 API（运行时）                   │
│       ▼                                               │
│  Cloudflare Workers API（.workers.dev 子域）           │
│   ┌─────────┬──────────┬───────────┬────────────────┐ │
│   │ D1 数据库 │ R2 照片   │ Stream 视频│ 管理后台 /admin│ │
│   │ (内容/留言)│ (10GB免费)│ (自动转码) │ (登录+管理)     │ │
│   └─────────┴──────────┴───────────┴────────────────┘ │
└─────────────────────────────────────────────────────┘
```

- **公开网站**：现有 vinext 静态导出，托管 GitHub Pages，URL 不变
- **后台数据**：管理后台写 D1 → 公开 API 读取 → 前端页面运行时渲染（新内容部分用 client component，与灵修的静态 JSON 数据并存不冲突）
- **媒体**：照片 → R2（免费 10GB）；视频 → Stream（自动转码多清晰度 + 自适应码率 + 内置播放器）
- **成本**：照片 R2 $0；视频 Stream 每月约 $0.7（主日讲道 4 场×60 分钟）；初期基本 $0

## 4. 数据模型（D1 表）

```sql
-- 活动记录（6 个专栏 + 敬拜 + 建堂共用）
CREATE TABLE posts (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  column_slug TEXT NOT NULL,      -- sunday-school / youth / worship / building ...
  title TEXT NOT NULL,
  date TEXT NOT NULL,             -- 活动日期
  content TEXT DEFAULT '',        -- 文字记录/见证
  cover TEXT DEFAULT '',          -- 封面（R2 URL 或 Stream 缩略图）
  created_at TEXT DEFAULT (datetime('now'))
);

-- 媒体（照片/视频，挂在某条活动记录下）
CREATE TABLE media (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  post_id INTEGER NOT NULL,
  kind TEXT NOT NULL,             -- photo | video
  url TEXT NOT NULL,              -- R2 地址 或 Stream 播放 ID
  caption TEXT DEFAULT '',        -- 说明
  sort INTEGER DEFAULT 0
);

-- 查经公告（每周一条）
CREATE TABLE bible_study (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  week INTEGER NOT NULL,          -- 周次（2026-W32）
  date TEXT NOT NULL,             -- 周五日期
  topic TEXT NOT NULL,            -- 查经主题
  passage TEXT DEFAULT '',        -- 查考经文
  zoom_url TEXT DEFAULT '',       -- Zoom 链接
  leader TEXT DEFAULT '',         -- 带领同工
  notes TEXT DEFAULT '',
  created_at TEXT DEFAULT (datetime('now'))
);

-- 爱心窗口留言（匿名/化名）
CREATE TABLE care_messages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT DEFAULT '匿名',       -- 称呼（可选，可匿名）
  contact TEXT DEFAULT '',        -- 联系方式（可选）
  category TEXT NOT NULL,         -- 人际关系/家庭/子女教育/信仰疑问/情绪压力/其他
  content TEXT NOT NULL,
  status TEXT DEFAULT 'new',      -- new → following → done
  created_at TEXT DEFAULT (datetime('now'))
);

-- 会员接纳申请（非基督徒 / 新朋友）
CREATE TABLE membership (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT DEFAULT '',
  contact TEXT DEFAULT '',        -- 微信/邮箱/电话
  intent TEXT DEFAULT '',         -- 想了解信仰 / 想参加聚会 / 想加入教会
  message TEXT DEFAULT '',
  status TEXT DEFAULT 'new',      -- new → contacted → done
  created_at TEXT DEFAULT (datetime('now'))
);

-- 管理员
CREATE TABLE admins (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,
  created_at TEXT DEFAULT (datetime('now'))
);
```

## 5. 管理后台 `/admin`（新开发）

- **登录**：账号密码（Workers 会话 cookie，密码哈希存 D1）
- **功能模块**：
  1. **活动记录**：按栏目新增/编辑/删除（标题、日期、正文、封面），上传照片（R2）/视频（Stream）
  2. **查经公告**：发布/编辑每周公告（周次、日期、主题、经文、Zoom、同工）；可设置"自动发布"（到每周四晚自动生成下一条？——先做手动发布，自动排期第二阶段）
  3. **爱心窗口**：留言列表（新/跟进中/已处理），查看详情，标记状态，**导出 CSV**
  4. **会员接纳**：申请列表，查看，标记状态，导出 CSV
  5. **媒体库**：照片/视频统一管理
- 后台 UI：轻量管理页（Workers 托管静态资源 + API），移动端可用

## 10. 风险与缓解

| 风险 | 缓解 |
|------|------|
| Workers API 免费额度（10 万请求/天） | 教会流量远低于此；加缓存（KV/`Cache-Control`）进一步降低 |
| D1 免费额度（5GB/500 万行读） | 内容型数据量极小，无忧 |
| Stream 100 分钟免费存储超限 | 讲道约 $0.7/月；短视频控制在免费额度内 |
| 静态站 + 运行时 API：首次加载慢 | 关键区块加缓存与骨架屏 |
| 管理后台安全 | 账号密码 + 会话 cookie + 仅管理员路径 |
